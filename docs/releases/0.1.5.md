Calendar Sync can now run only in the menu bar, with a setting to control whether it appears in the Dock.

### New in this release

- **Show in Dock** in the sidebar is on by default. Turn it off to hide the Dock icon and Command-Tab entry immediately.
- Your choice is remembered on this Mac. The menu-bar icon remains available; choose **Open Calendar Sync** to reopen the window and change the setting.
- The setting is disabled in sample-data mode. Existing rules, tracked copies, automatic syncing, and launch-at-login settings are preserved.

### Download and install

- **Apple Silicon:** `Calendar-Sync-v0.1.5-macos-arm64.zip`
- **Intel:** `Calendar-Sync-v0.1.5-macos-x86_64.zip`
- **Requires macOS 14 or later.** Intel is cross-compiled; runtime validation is performed on Apple Silicon.

Unzip the download and drag **Calendar Sync.app** into **Applications** (or `~/Applications` without administrator access). Existing users should quit Calendar Sync before replacing the app. Open it and allow Calendar access if asked. See the [README](https://github.com/wgtndan/outlookFlightSync#download-and-install) for setup, checksum verification, and build-from-source instructions.

These preview binaries are **ad-hoc signed, not Developer ID signed or notarized**. macOS may ask you to renew Calendar access after an update. If macOS blocks the download because its developer cannot be verified, follow [Apple's per-app Open Anyway instructions](https://support.apple.com/en-us/102445) only if you trust this release.

### Validation

The release passes **91 automated tests** using synthetic events and temporary databases. These checks do not establish complete behavior for every calendar provider or macOS version.

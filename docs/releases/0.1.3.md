Calendar Sync's first public preview copies selected events between calendars already connected to Apple Calendar. It runs locally on your Mac, with no hosted service or separate calendar sign-in.

### Download and install

- **Apple Silicon:** `Calendar-Sync-v0.1.3-macos-arm64.zip`
- **Intel:** `Calendar-Sync-v0.1.3-macos-x86_64.zip`
- **Requires macOS 14 or later.** Intel is cross-compiled; runtime validation was performed on Apple Silicon.

Unzip the download, drag **Calendar Sync.app** into **Applications** (or `~/Applications` without administrator access), open it, and allow Calendar access. See the [README](https://github.com/wgtndan/outlookFlightSync#download-and-install) for setup, checksum verification and build-from-source instructions.

These preview binaries are **ad-hoc signed, not Developer ID signed or notarized**. If macOS blocks the downloaded app because its developer cannot be verified, follow [Apple's per-app Open Anyway instructions](https://support.apple.com/en-us/102445) only if you trust this release. Do not disable Gatekeeper. Developer ID signing and notarization are future work.

### Included

- Account-aware source/destination calendar selection and editable matching conditions.
- Flights, Family Commitment and custom presets.
- A preview before writing, with **Apply this change** to test one event or **Apply all changes** for the full batch.
- Title, time, location and notes copying for flights/custom rules. Notes edits and removals also update existing copies.
- Family copies titled **Family Commitment**, with busy time and descriptive details removed.
- Optional automatic creates/updates every five minutes and after wake; removals always require manual confirmation.
- App icon, Dock/Command-Tab access, menu-bar controls and optional launch at login.
- Ownership checks and recovery for interrupted writes, including the original prototype's post-save verification failure.

### Existing users

Quit the app before replacing it in Applications. Rules and mappings remain intact. Calendar access may need renewal after replacing an ad-hoc signed build. Flight/custom rules approved before notes copying was introduced pause until you review a new full preview. Existing copies get notes when you apply their updates.

### Limits and validation

Both accounts must already sync in Apple Calendar; Outlook sign-in alone is insufficient. The family preset removes details but **does not set Outlook's Private flag**. Attachments, rich formatting, attendees and reminders are omitted. Recurring source events become individual occurrence copies. Some rescheduled source identities require manual review.

The release passes **76 automated tests** using synthetic events and temporary databases. Tests cover reconciliation, ownership, recovery, single-change application, notes, persistence and EventKit field handling. This does not establish complete behavior for every calendar provider or macOS version.

Calendar Sync now opens to a Summary of your rules, making it easier to review what each rule copies and which rules need attention.

### New in this release

- Rule cards show source and destination accounts/calendars, conditions, copied details, date coverage, and status.
- Search rules, presets, calendars, and conditions; filter by All rules, Needs attention, Automatic, or Manual.
- See tracked local copy counts and the last recorded result for each rule. Counts include retained history and are not a live inventory of calendar events.
- Choose **Review rule** to open its settings and test a fresh preview. Summary does not apply changes or start syncing.
- New activity records use stable rule IDs, so renamed rules keep their history and duplicate names do not mix results. Earlier activity remains visible in Recent activity.

Calendar matching, copying, approvals, and automatic-sync behavior are unchanged.

### Download and install

- **Apple Silicon:** `Calendar-Sync-v0.1.4-macos-arm64.zip`
- **Intel:** `Calendar-Sync-v0.1.4-macos-x86_64.zip`
- **Requires macOS 14 or later.** Intel is cross-compiled; runtime validation is performed on Apple Silicon.

Unzip the download, drag **Calendar Sync.app** into **Applications** (or `~/Applications` without administrator access), open it, and allow Calendar access. Existing users should quit Calendar Sync before replacing the app. Rules and mappings remain intact; macOS may ask you to renew Calendar access after replacing an ad-hoc signed build. See the [README](https://github.com/wgtndan/outlookFlightSync#download-and-install) for setup, checksum verification, and build-from-source instructions.

These preview binaries are **ad-hoc signed, not Developer ID signed or notarized**. If macOS blocks the downloaded app because its developer cannot be verified, follow [Apple's per-app Open Anyway instructions](https://support.apple.com/en-us/102445) only if you trust this release. Developer ID signing and notarization remain future work.

### Limits and validation

Both accounts must already sync in Apple Calendar; Outlook sign-in alone is insufficient. The family preset removes details but **does not set Outlook's Private flag**. Attachments, rich formatting, attendees, and reminders are omitted. Recurring source events become individual occurrence copies. Some rescheduled source identities require manual review.

The release passes **91 automated tests** using synthetic events and temporary databases, including Summary status, counts, and rule-history compatibility. They do not establish complete behavior for every calendar provider or macOS version.
